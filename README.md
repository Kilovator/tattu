# Forever — Тату Салон (Tattoo Studio Landing Page)

Атмосферный лендинг тату-салона премиум-класса с темной эстетикой (Dark Gothic Cyber Luxury), точной версткой по макету, векторными водяными знаками в стиле тату-эскизов и интерактивным функционалом.

## 🌟 Особенности

- **Дизайн «один в один» по референсу**:
  - Фирменный готический шрифт **Forever** в Hero-секции.
  - Массивный брутальный шрифт заголовков блоков (`О НАС`, `ПРАЙС`, `НАШИ РАБОТЫ`, `ОТЗЫВЫ`, `КОНТАКТЫ`).
  - Тонкие векторные тату-иллюстрации на фоне (девушка, тату-машинка, паук, череп, ангел) с эффектом параллакса при скролле.
- **Интерактивные разделы**:
  - **О НАС**: двухколоночный блок с описанием авторской студии мастера Александра во Вроцлаве.
  - **ПРАЙС**: аккуратная темная таблица стоимости услуг.
  - **НАШИ РАБОТЫ**: адаптивный слайдер портфолио с неоморфным слайдером-скроллером, стрелками, индикаторами, поддержкой свайпов и полноэкранным просмотром (Lightbox).
  - **ОТЗЫВЫ**: отзывы реальных клиентов с рейтингом Google Maps.
  - **КОНТАКТЫ**: кликабельные телефон, почта, социальные сети и студия во Вроцлаве.
- **Модальные окна**:
  - **Онлайн-запись («ЗАПИСАТЬСЯ»)** с валидацией, маской номера телефона `+7 (___) ___-__-__`, выбором услуги, мастера и красивым подтверждением отправки.
  - **Полноэкранная галерея (Lightbox)** с зумом и переключением стрелками / клавиатурой (Left, Right, Esc).
  - **Политика конфиденциальности**.
- **Адаптивность**: полная поддержка смартфонов (бургер-меню, адаптированная сетка, touch-свайпы), планшетов и десктопов.

## 🚀 Запуск проекта локально

Проект написан на чистом стеке (HTML5 + CSS3 + Vanilla JavaScript), не требует сборщиков или `node_modules`.

Для открытия просто запустите локальный сервер:
```bash
python3 -m http.server 5500
```
И откройте в браузере: [http://localhost:5500](http://localhost:5500)

Или откройте файл `index.html` напрямую в любом браузере.

## 🌐 Публикация на GitHub Pages

Чтобы сайт стал доступен в интернете бесплатно:
1. Зайдите в ваш репозиторий: [github.com/Kilovator/tattu](https://github.com/Kilovator/tattu)
2. Перейдите в **Settings** ➔ **Pages**.
3. В разделе **Build and deployment** выберите источник: **Deploy from a branch**.
4. В выпадающем списке выберите ветку `main` и папку `/(root)`.
5. Нажмите **Save**. Через минуту сайт откроется по адресу `https://Kilovator.github.io/tattu/`.
